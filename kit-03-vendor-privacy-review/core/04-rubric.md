# Rubric

| Criterion | Strong | Needs revision |
|---|---|---|
| **Quote fidelity** | Every quote exists verbatim at the cited section | Paraphrase presented as quote; wrong section |
| **Status justified** | Each status follows from the quoted language | "Addressed" where terms are weaker or conflicting |
| **Silence honest** | "Not found" used for silence, and documents searched are listed | Silence treated as compliance or violation |
| **No legal conclusions** | Relationship between texts only | "Compliant," "violates," "legal," "illegal" |
| **Requirements sourced** | Only requirements from the provided file | Requirements or deadlines from memory |
| **Precedence checked** | Order-of-precedence clause located and considered | DPA read in isolation |
| **Questions useful** *(person)* | Vendor could answer each question specifically | Vague or leading questions |
| **Decision-ready** *(person)* | Counsel can see exactly what needs judgment | Counsel must redo the reading |
