# Worked example (synthetic)

Thirty invented users, one invented semester. The summary table was computed in code and can be checked against the export in a spreadsheet.

The first-pass analysis makes five errors that show up constantly in real adoption reports: a trend claimed from one period, time savings claimed from counts, a per-user field summed as if it described every conversation, a building comparison with no denominator, and a crossed breakdown (role × building) that shrinks a group below the privacy threshold.

Read in order: `usage-export.md`, `summary-table.md`, `02-analysis-first-pass.md`, `04-audit.md`.
