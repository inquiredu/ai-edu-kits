# Rubric

| Criterion | Strong | Needs revision |
|---|---|---|
| **Computed figures** | Every number traces to the summary table or shown code, and recomputes | Numbers generated in prose; don't recompute |
| **Measure fidelity** | Claims stay within what the fields measure | "Time saved," "impact," "quality" from counts |
| **Time honesty** | One period described as one period | "Growing," "declining," "trend" from a snapshot |
| **Attribution level** | Group claims carry counts; small groups merged or omitted | Groups characterized from a handful; buildings ranked |
| **Valid derivations** | Category and other fields used as defined | Per-user fields summed as if per-conversation |
| **Privacy** | No group under `{{MIN_CELL}}`; no path to an individual | "The only ___" or a count of one or two in a named group |
| **Tone** *(person)* | Stalls framed as conditions; staff respected | Deficit or ranking language |
| **Actionable** *(person)* | Findings connect to changes the district can make | Descriptive only |
