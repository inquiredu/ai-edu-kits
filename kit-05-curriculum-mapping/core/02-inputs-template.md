```

```

Shared context (one file):

```
# Mapping context
AI use scale: {{AI_USE_SCALE}}  (paste each level with its full definition)
Approved tools for grade {{GRADE}}: {{APPROVED_TOOLS}}
Grade-level AI progression: {{PROGRESSION}}
Local values: {{LOCAL_VALUES}}

## Evidence pack (optional)
E1 | [citation] | [passage you vetted] | [vetted by]
```

Paste standards verbatim from the official source. The mapper will not supply standards from memory, and standards differ by state and adoption year.
