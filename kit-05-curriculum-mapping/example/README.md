# Worked example

Two real grade 7 English Language Arts standards from the Common Core State Standards (verbatim), used for illustration — your state's standards may differ. The district, scale, tools, and moments are invented.

The first-pass mapping contains the three errors the reviewer exists to catch: AI performing the verb the standard names, students producing a deepfake, and an unsupported effect claim. It also shows the reviewer salvaging a strong idea buried inside a failing moment.

Read in order: `context-and-standards.md`, `01-map-first-pass.md`, `02-review.md`.

`03-approvals.md` defines the human decision record. It is intentionally unfilled: the reference review triggers the majority-CUT stop, and no example approval may bypass that stop.
