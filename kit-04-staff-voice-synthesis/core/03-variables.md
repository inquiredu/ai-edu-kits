# Variables

Fill these in once. Every role prompt uses the same `{{NAME}}`. In Claude Code, save a filled copy as `config.md` in the kit folder.

| Variable | What it is | Example |
|---|---|---|
| `{{DISTRICT}}` | Your district or organization | Lakeview Public Schools |
| `{{GROUP}}` | Who gave the input | Middle school instructional staff |
| `{{QUESTION}}` | The exact question asked, verbatim | What do you need to feel confident about students using AI in your classroom this year? |
| `{{COLLECTION_METHOD}}` | How input was gathered | Anonymous form, optional role field |
| `{{PURPOSE}}` | What the synthesis will inform | A building-level AI expectations framework for spring |
| `{{DECISION_OWNER}}` | The person who owns Gate 3 | Building principal |
| `{{FRAMEWORK_TYPE}}` | What the Drafter produces | Staff-facing expectations framework (1–2 pages) |
| `{{LOCAL_VALUES}}` | Values or strategic plan language the framework may connect to, where it adds clarity | Scholarship; Character; "lifelong learners and ethical citizens" |
| `{{APPROVED_TOOL}}` | Your approved AI environment, or "none — de-identified only" | Google Gemini (Workspace for Education) |
| `{{MIN_GROUP_SIZE}}` | Smallest role group that may be named | 3 |
| `{{MIN_THEME_SIZE}}` | Fewest responses that may be called a theme; smaller clusters are reported as single or paired voices | 3 |
| `{{READING_LEVEL}}` | Audience for the draft framework | Staff; plain language, no jargon |

Two of these do most of the protective work. `{{MIN_GROUP_SIZE}}` keeps role labels from identifying people. `{{MIN_THEME_SIZE}}` keeps two comments from becoming "a theme." Set both before you run anything, not after you see results.
