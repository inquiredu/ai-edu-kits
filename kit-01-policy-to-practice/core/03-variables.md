# Variables

| Variable | What it is | Example |
|---|---|---|
| `{{DISTRICT}}` | Your district | Lakeview Public Schools |
| `{{POLICY_NUMBER}}` | Policy number | 999 |
| `{{POLICY_TITLE}}` | Policy title | Responsible Use of Technology Tools |
| `{{AUDIENCES}}` | Who each translation serves | Building administrators (guide, 2–4 pages); instructional staff (one page) |
| `{{POLICY_OWNER}}` | Who rules on interpretation | Superintendent, with district counsel as needed |
| `{{ROUTING}}` | Where people send questions the policy doesn't answer | Building principal first; district technology office for tool questions |
| `{{LOCAL_VALUES}}` | Values or strategic-plan language that may be used where it adds clarity | Scholarship; Character |
| `{{READING_LEVEL}}` | Staff one-pager reading target | Plain language; a teacher can read it in three minutes |
| `{{CURRENT_TOOLS_SOURCE}}` | Where the current approved-tool list lives, so the translation points there instead of naming tools | District technology webpage, "Approved Tools" |

Pointing to `{{CURRENT_TOOLS_SOURCE}}` instead of listing tools keeps the translation from going stale the next time a tool changes.
